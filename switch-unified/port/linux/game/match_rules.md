# Host match presets and map requirements

The host applies native game variants before publishing the setup. Multiplayer
objects carry the host-selected biped definition through the existing object
replication; no new wire fields or foreign map assets are introduced.

- **Faction match:** Covenant/USMC, USMC/Flood, or Flood/Covenant. Each team
  gets a deterministic per-player/per-death choice among safe biped tags loaded
  by the map. Missing assets keep the map's standard biped and explicitly
  report that the selected map must already contain the faction assets; no
  automatic delivery is claimed.
- **SWAT:** team Slayer, no shields, pistol custom loadout, no map weapons,
  starting grenades, or vehicles. It does not implement headshot-only damage
  or add a Battle Rifle.
- **Tower of Power:** team Slayer with shotgun loadout. Tower geometry and
  placements must come from the map.
- **Grenade Dodgeball:** team Slayer, empty custom starting loadout, infinite
  grenades, no shields, no map weapons, and no vehicles.
- **Zombies:** works with stock map assets. The host chooses one initial
  infected from at least two players. Human deaths convert to infected; late
  joiners enter infected. Infected carry the map's loaded Oddball, Flag, or
  pistol melee weapon when one is available. The held weapon is selected;
  host-side input filtering blocks firing, grenades, reload, and weapon
  switching while preserving the melee control. The host also rejects
  non-melee damage reports from infected clients. If the held weapon cannot be
  created or added, the existing inventory stays intact and infected still
  cannot fire; native unarmed melee remains available when that biped permits
  it. The extended lunge is negotiated between matching clients; older clients
  still join and use ordinary melee without the lunge. Flood bipeds are used
  when loaded; otherwise infected keep the normal
  appearance. Survivors keep the map's standard loadout. Built-in team
  elimination and time limit determine the outcome.
- **Native Race:** the existing team Race engine is used. The selected map
  must contain at least two Race Track netgame markers; geometry is not
  generated by this preset.

Preset availability checks expose these map and player-count requirements.


## Gun Game

Gun Game is a host-authoritative Slayer preset using stock map-loaded weapon
definitions. A credited enemy player kill advances the killer one stage;
suicides, invalid killers, and friendly fire do not. Death and respawn preserve
the player's stage. A changed player datum in a reused roster slot starts at
the pistol stage. Late joiners also start at the pistol stage.

The seven stages are pistol, assault rifle, plasma rifle, needler, shotgun,
sniper rifle, then rocket launcher. Six credited kills advance the player to
rocket launcher; the next credited enemy kill wins. Any separately credited
enemy kill advances the current stage, regardless of which earlier-stage
projectile caused it. Rocket launcher is last, so its delayed multikills cannot
skip earlier stages. The host synchronizes the ordinary FFA Slayer scoreboard
to progression after credited, suicide, and friendly-fire events, so penalties
cannot cause an early or missed win. Player kill/death statistics stay intact.
The selected map must already load all seven stock weapon tags;
the host status reports when it does not. Map weapon pickups, grenades, and vehicles are
disabled for the mode. The host sends the ordinary weapon objects/inventory
through existing replication, with no new client protocol fields. Unchanged
clients therefore receive normal stock weapon stages, but do not get a new
Gun Game UI or mode-specific restrictions; host authority enforces pickups.
