# Steam Deck/Linux 2.9.5

## Lobby settings

Hosts can use EDIT MATCH in the waiting multiplayer lobby, choose a map and game type, edit its options, then choose APPLY TO LOBBY. Two native peers passed map, Oddball and score changes while staying connected.

## Voice options

Audio Settings has Voice Chat, Voice Mode, Lobby/Menu Voice and Push-to-Talk. Choose OK to save.
Voice Chat and Lobby/Menu Voice both default OFF. Voice Mode offers Push to Talk or Open Mic.
Lobby/Menu Voice allows conversation while connected to a waiting lobby or using pause menus. The unjoined main menu does not record.
Compatible native clients are required. Lobby voices are centered; gameplay uses player positions.
Two native clients passed silent generated-audio transmission, reception and output-file analysis in a lobby, gameplay and a pause menu. Hardware microphones and real player capacity remain untested.

## Modes and content

Zombies survivors use shotguns and infected use stock melee objects. Tower of Power uses shotguns and stationary turrets, with no shields, radar or floor weapon pickups. Two native peers passed shotgun-only inventory checks. Lunge runtime behavior, turret retention and full mode acceptance still need testing; a playable sword is not included.

Ghost boost is available on keyboard L and controller LB/L1. Native keyboard testing measured about 1.75 times ordinary speed. Physical-controller boost is not yet confirmed.

Race uses authored checkpoints and allows additional initial vehicles when the map has enough spawn flags. Large races still need real-player testing.

Content has map category, installed-state, alphabetical sorting, search and pages. The optional texture library has search, pages, selected-pack status and recoverable removal.

A complete online mod store, arbitrary CE scripting/shader mods, finished campaign-section faction maps, persistent friends, physical Switch acceptance and full natural campaign completion remain open. This release is for Linux; it does not replace the Switch executable.

Supply your own compatible game data. No maps, saves, profiles or keys are included.
