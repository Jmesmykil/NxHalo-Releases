# Credits and notices

NxHalo builds on the native-port and decompilation work of [bnunu/halo](https://github.com/bnunu/halo) and [punpckhdq/halo](https://github.com/punpckhdq/halo), with Switch integration by NxHalo contributors through Astral.

This source-only importer archive contains original project setup code and an original procedural loading image generator, covered by the project [CC0 notice](../LICENSE.md). No third-party runtime library, packer executable or proprietary game file is shipped in this archive.

The parser implementation follows the XDVDFS layout documented by [XboxDev/extract-xiso](https://github.com/XboxDev/extract-xiso/blob/master/extract-xiso.c) and [xdvdfs-core](https://github.com/antangelo/xdvdfs/blob/main/xdvdfs-core/src/read/dirent_table.rs). Python and Tk are separately installed dependencies with their own notices. DBI and hacBrewPack are separate tools; neither is bundled here.

Runtime component notices accompany runtime releases separately. The broader source repository also contains separately licensed components; the root CC0 notice does not relicense third-party components or game data.
