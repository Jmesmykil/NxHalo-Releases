# Native texture catalogue

This catalogue supplies compatible image replacement packs to the in-game Online Texture Packs browser. The first entry contains one Alpine-specific authored texture. It is not a general CE mod store: DLL, Lua, shader extensions, weapons and maps require their own supported paths.

Choose a pack to read its author, license and map requirements before installation. Downloads are bounded, SHA-256 checked and installed atomically. Installation does not enable a pack. Use Installed Packs to select, enable, disable or move it to recovery.
