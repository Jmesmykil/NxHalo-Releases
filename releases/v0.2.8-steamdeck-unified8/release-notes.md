# Unified Steam Deck Preview 2.8

Repairs controller routing with a single selected gamepad and stable device identity; directly connected PlayStation controllers take priority over built-in Deck controls. Keyboard/mouse and split-screen assignments remain supported. Slows held menu navigation repeat from 250ms to 350ms. The creator confirmed PS5 gameplay and menu controls on the prior e09 controller build; this release retains that input source unchanged. Includes native Team SWAT, Tower of Power, grenade Dodgeball, infection and Race presets plus map-local faction teams. Faction selection activates its preset. Race requires race flags and Tower of Power requires suitable map geometry. These options do not generate map geometry or add missing assets to other clients. Host team changes use stock replicated unit ownership on respawn; live multi-client preset matches remain unverified.


One executable replaces the prior NxHalo/OpenCE split. The main menu includes Custom Maps & Mods and a network chooser for campaign join/host, multiplayer host, separately filtered discovery and local split-screen. Native runtime profiles 11/20/21 are selected in-process; no legacy/campaign process handoff is needed. V11 is multiplayer-only. The original installed app path and saves are retained with rollback backups.

Merged the existing native CE609/retail7 map loader, companion-resource checks and CE pixel layouts into the campaign engine while preserving newer tag/texture validation. Added bounded map downloads, local map/ZIP/resource import, same-room missing-map retry, native character selectors, campaign third-person and host/co-op spawn presets using map-local bipeds. Retained responsive roster/player inspection and confirmed console moderation. Stock multiplayer maps do not automatically contain campaign-only assets.

Fixed the archive-reopen error: SDL cache and file-dialog paths now bypass Xbox path translation. The previous game fopen shim looked for the native cache file under the Xbox data tree. Corrected lobby focus highlights and native mouse targets to match the responsive toolbar/roster, regenerated all six button definitions, and retained remote selection when focus moves to moderation buttons. Registered missing preset/faction config keys and verified write/reload. Map downloads now expose map-specific HTTP, response-type, destination and archive errors. The production HTTP client and extractor imported HaloNet Blood Gulch in an isolated Omarchy harness; this does not prove the reported Deck UI failure is fixed. CE maps can require owner-supplied resource companions.

The keepalive schema decoded four bytes into a two-byte C record and reproduced a host stack-protection abort. Encoding now uses zero-padded owned scratch; decoding checks the expected message type and copies only the logical record size. An independent source review checked the 35-entry logical-size mapping. Archive fixtures passed stored/deflate/nested extraction, traversal/absolute/duplicate/unrelated/wrong-magic rejection, and existing destination/partial preservation. Native linking passed. The final Linux binary is installed on the Deck and its file hash is verified; the currently running process remains the prior 5baaae build until next launch. Dialog redraw was confirmed at runtime and a clean world frame was captured, but stock modal styling has not received human physical acceptance. Earlier physical captures show the content and network menus. Three private headless profiles initialized and requested game start after the fix, then were stopped by the test harness; synthetic-peer joins did not succeed. These are not real-client interoperability or full-match proofs.

A 22-second native Linux CE Death Island smoke loaded the actor and reached ticks31-394 with the world, weapon and HUD rendered, using owner-provided CE resources. The companions remain private and are excluded from release artifacts. BSP range checks and HS script/string checks now use the CE arena; CE BSP validation uses its own schema instead of the stale Xbox-map schema. A separate nativepair discovery probe did not join, and the short solo run logged a late connection-silence warning. This is not sustained multiplayer or physical Switch acceptance. Resource companions remain private and are not supplied in releases. Two-real-client compatibility, custom-character matches, co-op BSP/damage synchronization, full map-download-and-join and controller moderation remain unverified. Friends/voice and classic PC engine-extension ports remain future work. No claim that every CE mod is ported. Classic PC/CE address snapshots remain separate and not native-joinable. No game maps, console keys or personal saves packaged. Older releases remain available.
