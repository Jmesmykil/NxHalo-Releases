# NxHalo Profile33 release package

This folder contains the public Profile33 prerelease assets plus the unchanged offline setup tools from Build14. Start with `RELEASE-NOTES.md`; use `SHA256SUMS` to verify each file.

`Halo_CE_Profile33.nsp` is copied from the UMS-staged Profile33 installer and its hash matches the validation receipt. Staging and readback do not mean that it was installed or accepted on physical Switch hardware. The exact matching runtime source snapshot is `NxHalo-Profile33-runtime-source.zip`.

The Profile33 title ID differs from Build14, so this is a separate title rather than an in-place Build14 update. No game data, maps, ROM, executable, shader instruction data, keys or saves are included.
