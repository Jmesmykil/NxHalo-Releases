# Unified Steam Deck Preview 2.7

One executable replaces the prior NxHalo/OpenCE split. The main menu includes Custom Maps & Mods and a network chooser for campaign join/host, multiplayer host, separately filtered discovery and local split-screen. Native runtime profiles 11/20/21 are selected in-process; no legacy/campaign process handoff is needed. V11 is multiplayer-only. The original installed app path and saves are retained with rollback backups.

Merged the existing native CE609/retail7 map loader, companion-resource checks and CE pixel layouts into the campaign engine while preserving newer tag/texture validation. Added bounded map downloads, local map/ZIP/resource import, same-room missing-map retry, native character selectors, campaign third-person and host/co-op spawn presets using map-local bipeds. Retained responsive roster/player inspection and confirmed console moderation. Stock multiplayer maps do not automatically contain campaign-only assets.

The keepalive schema decoded four bytes into a two-byte C record and reproduced a host stack-protection abort. Encoding now uses zero-padded owned scratch; decoding checks the expected message type and copies only the logical record size. An independent source review checked the 35-entry logical-size mapping. Archive fixtures passed stored/deflate/nested extraction, traversal/absolute/duplicate/unrelated/wrong-magic rejection, and existing destination/partial preservation. Native linking and installed Deck SHA match passed; physical captures show content and network menus. Three private headless profiles initialized and requested game start after the fix, then were stopped by the test harness; synthetic-peer joins did not succeed. These are not real-client interoperability or full-match proofs.

Real CE map gameplay still needs compatible owner resource companions. Two-real-client compatibility, custom-character matches, co-op BSP/damage synchronization, full map-download-and-join and controller moderation remain unverified. Friends/voice and classic PC engine-extension ports remain future work. No claim that every CE mod is ported. Classic PC/CE address snapshots remain separate and not native-joinable. No game maps, console keys or personal saves packaged. Older releases remain available.
